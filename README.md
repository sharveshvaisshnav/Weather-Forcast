# Weather Forecast Application

A lightweight, clean, and responsive weather forecasting web application that provides real-time weather information and coordinates tracking using vanilla JavaScript, HTML, and CSS.

## 🚀 Features
* **Real-time Weather Data:** Fetches up-to-date weather details for searched cities.
* **Coordinate Tracking:** Utilizes a dedicated coordinates script (`coordinate.js`) to handle location metrics.
* **Responsive Design:** A beautifully styled user interface featuring a dynamic `background.jpg` that adapts cleanly to different screen sizes.
* **Zero Dependencies:** Built entirely with native web technologies (HTML5, CSS3, JavaScript).

## 📁 Repository Structure
The project consists of the following core files:
* `index.html` - The main structure and user interface of the application.
* `style.css` - Custom styling, layout rules, and visual aesthetics.
* `script.js` - Logic for fetching weather API data and updating the UI dynamically.
* `coordinate.js` - Dedicated logic for managing geographical coordinates and location-based data.
* `background.jpg` - High-quality background asset used for the UI theme.

## 🛠️ Built With
* **HTML5:** Semantic markup structure.
* **CSS3:** Responsive layout design and styling.
* **JavaScript (ES6+):** Async API handling, DOM manipulation, and location tracking.
